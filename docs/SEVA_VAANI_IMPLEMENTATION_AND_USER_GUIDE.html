1. Executive Summary & Capabilities

SEVA VAANI bridges the digital divide for Indian citizens by replacing complicated web forms with an auditable, voice-first conversation in vernacular languages (Hindi, Marathi, English, etc.). It strictly enforces Zero Unconfirmed Submissions—guaranteeing that no personal information is permanently saved without explicit citizen confirmation.

🛡️ DPDP Act 2023 Privacy Firewall

Client-side regex firewall redacts Aadhaar (12-digit) and OTPs before data touches servers or logs. Sensitive applicant details are shielded with Argon2id and encrypted local storage.

🧠 Deterministic State Machine

Form progression is strictly state-machine driven. No LLM hallucination or field skipping occurs. Section 15 validation enforces: ≥0.85 (Confirm), 0.60–0.84 (Clarify), <0.60 (Repeat).

3. End-to-End Citizen User Journey

Stage Citizen Action System Response & Safety Gate
1. Service Selection Selects language (Hindi / Marathi / English) and clicks आय प्रमाण पत्र (Income Certificate). Initializes session state with zero unconfirmed values. Displays vernacular prompts.
2. Voice Ingestion Taps mic button and speaks: "मेरा नाम रमेश कुमार है". Extracts name candidate (Confidence ≥ 0.85). Asks: "क्या आपका नाम रमेश कुमार है? हाँ या ना कहें।"
3. Confirmation Gate Citizen speaks: "हाँ" (Yes). Value permanently committed to sessions state. Advances to next field (Phone Number).
4. Income Parsing Speaks natural vernacular number: "डेढ़ लाख रुपये". Normalizer converts to numeric 150000. Prompts confirmation before locking.
5. Review & Consent Reviews complete summary table and clicks Consent. DPDP audit record saved. Generates official Application ID (APP-2026-INC-XXXXX).

4. 3-Tier Fallback & Escalation Flow

If speech recognition encounters noise, strong regional accents, or microphone issues, the system automatically degrades gracefully:

Tier 1: Slow Audio Replay

Upon 1st unclear utterance (<0.60), the TTS engine repeats the prompt at 0.70x speed with clear diction to assist citizens with auditory difficulties.

Tier 2: Text Typing Fallback (FR-010)

Upon 2nd consecutive failure, an accessible on-screen text input keyboard appears automatically, allowing direct text entry while retaining all session progress.

Tier 3: Human Help Ticket Desk (FR-011)

Clicking "🆘 इंसानी सहायता (Human Help)" opens the dedicated 3-tab support interface:

  • Tab 1 (सहायता का अनुरोध): Select from 5 categories (Voice, Form, Server, Docs, Other) ➔ Generates official ticket ID: TKT-XXXXXX.
  • Tab 2 (मेरे टिकट्स): View ticket history and real-time status (OPEN, IN_PROGRESS, RESOLVED) with user-isolation (403 prevention).
  • Tab 3 (हेल्पलाइन संपर्क): Direct one-click dialer (Kisan Call Center: 1551, Women Helpline: 181, e-District: 1800-180-6127).

5. PWA Offline & Chrome Extension Features

📱 PWA Offline Support

• Installable: Click "Install App" in Chrome to use as a native desktop or mobile application.
• Offline Drafts: Unsent forms are safely stored in browser IndexedDB and automatically synchronize when internet restores.

🧩 Chrome Extension (MV3)

• Portal Overlay: Injects a floating voice mic onto live government portals (NSP, MahaDBT).
• DOM Auto-Mapper: Maps spoken values directly into portal form fields inside an isolated Shadow DOM container.
