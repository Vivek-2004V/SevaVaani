1. The Problem Hook & Value Proposition 0:00 – 0:25 (25s)

Speaker Script: "850M+ Indians speak regional languages, but digital welfare portals (Post-Matric Scholarships, e-District) are text-heavy and English-dominant. Citizens are forced to pay middlemen at CSCs just to fill forms. SEVA VAANI changes this: an auditable, voice-first digital assistant in 11 Indian languages that operates both as an installable offline PWA and an in-page Chrome Extension on live government portals, with mathematically enforced Zero Unconfirmed Commits."

2. Live Multilingual Voice Interaction (Hindi + Marathi) 0:25 – 0:55 (30s)
Turn 1 (Hindi Name Extraction): Citizen speaks: "मेरा नाम विवेक विश्वकर्मा है"
➔ Web Speech STT captures utterance ➔ NLU extracts candidate विवेक विश्वकर्मा (Conf: 0.96) ➔ Confirmation Gate fires.
➔ Assistant speaks: "आपका नाम विवेक विश्वकर्मा है, क्या यह सही है?" ➔ Citizen: "हाँ, सही है" ➔ Committed.
Turn 2 (Marathi Natural Number Normalizer): Citizen speaks: "माझे वार्षिक उत्पन्न एक लाख ऐंशी हजार रुपये आहे"
➔ Compound phrase parsed to integer 180000 ➔ Marathi prompt: "आपले वार्षिक उत्पन्न ₹1,80,000 आहे, बरोबर आहे का?" ➔ Citizen: "हो, बरोबर आहे" ➔ Committed.

Pan-India Dialect Switch: Switch to Bengali (বাংলা), Tamil (தமிழ்), or Gujarati (ગુજરાતી) mid-session; previous field values remain strictly intact.

3. Low-Confidence Handling & Truthful Human Helpdesk 0:55 – 1:25 (30s)

Low Confidence (< 0.60): "When uncertain, do not guess." The system rejects noisy audio and asks a polite clarification prompt rather than hallucinating wrong names.

2-Failure Tier: UI presents the Text Typing Fallback card for manual entry without restarting.
3-Failure Tier: Citizen taps "🆘 इंसानी सहायता (Human Help)" ➔ Creates authentic SQLite record TKT-XXXXXX ➔ UI truthfully confirms storage without fabricating external operator alerts.
4. Government Portal Extension & Explicit Consent Barrier 1:25 – 2:00 (35s)

Chrome Extension Demo: Floating widget injects into live government portal (scholarships.gov.in / MahaDBT), auto-maps DOM fields, and guides the citizen directly in the live browser tab.
Strict Consent Barrier: Submissions without explicit consent return status: blocked. With consent, system issues official permanent reference ID: SV-SCH-2026-XXXXXX.
